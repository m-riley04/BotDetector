# Privacy

## Permissions Justifications

### `storage`

I use the `storage` permission to store extension settings and cached bot detections for a smoother user experience.

### `clipboardWrite`

I use the `clipboardWrite` permission to allow users to easily copy/paste settings and post/user JSON data.

### Host permission

For many social media sites, they shorten all their links through a proxy for tracking. I use their proxy to get the actual link that's being stored, WITHOUT sending any data there. Additionally, some users use link shorteners to hide suspicious-looking links. I use that host permission to de-shorten links safely.

### Remote Code

I am NOT using remote code.

## Data Usage/Collection

The data that I USE in the extension are as follows:

- Website Content (for reading/scraping social media posts)

> NOTE: I do not store ANY of this content on my servers; it is all stored locally.
> In the future, I may try to hook-in a server so that I can test and get more accurate results, but for now, no data is stored elsewhere.

### Disclosures

- I do not sell or transfer user data to third parties
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose
- I do not use or transfer user data to determine creditworthiness or for lending purposes
